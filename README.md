# Suhail for Poplin

Presentation deck for my application to Poplin (UI Engineer and AI Product Designer roles).

- `deck/deck.json`: slide order and sections
- `deck/slides/*.html`: one HTML file per slide (1920x1080, Claude Slides format)
- `assets/minneapolis_map.png`: muted Minneapolis street map used on the cover. Built from City of Minneapolis open data (street centerlines and water). The cover slide references it as an uploaded asset, so re-upload this file if you rebuild the deck elsewhere.
